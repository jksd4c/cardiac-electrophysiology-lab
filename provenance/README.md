# 来源记录的解释

organui-manifest.json 和 organui-ATTRIBUTION.upstream.md 为固定提交核对的上游材料。上游文档中的相对链接指向上游仓库，不能假定该仓库的所有目录都包含在本包。活动的本项目署名位于 work/assets/ATTRIBUTION.md，使用本包存在的清单和固定上游 URL。

上游 retrieved 日期不是本项目的获取日期。verification.json 记录本次核对方式及边界；八个左房／肺静脉 OBJ 对照的是既有获取记录，本次没有重新下载整个官方源档案。原始 OBJ 的历史许可头未被改写。

这些记录沿用 v0.1 的解剖资产核验。v0.1.1 未改变网格和运行库；本版构建文件校验另见根目录 SHA256SUMS.json。
